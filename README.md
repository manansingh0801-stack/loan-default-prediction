# Loan Default Prediction

## Project Overview
This project predicts whether a borrower may default on a loan using machine learning.

## Dataset
The project uses `loan_default.csv`, which contains information about borrowers and their loans.

## Algorithms Used
- Decision Tree Classifier
- Logistic Regression

## Results
- Logistic Regression Accuracy: 83.6%
- Decision Tree Accuracy: 76.1%
- Tuned Decision Tree Accuracy: 80.6%

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Conclusion
The models were trained and evaluated to compare their performance in predicting loan defaults.
